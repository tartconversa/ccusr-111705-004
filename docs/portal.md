# 本地来源行为

非遗市集目录列出稳定的 `data-key` 和详情路径；详情需由浏览器导航读取，`月份`选择改变当前页面状态，`单日抽屉`和`摊位弹窗`是分步出现的可见内容。月底跨月时抽屉缓存与列表不同步。详情接口是浏览器页面，不是业务 API；运行时只允许访问环回来源。

`fixtures/portal.json` 提供合成业务资料，不包含真实个人数据。`records.save_catalog` 覆盖同一目录身份；`records.save_detail_entries` 以业务键追加入口访问，不把入口访问等同于资格、授权、可预约或正式提交。测试均只访问本地环回页面。

## 日历巡查的来源约定

- 月份只能沿“下一月”向前导航，没有回退按钮；巡查在发现全部月份后重新加载详情页，避免把发现阶段的页面状态带进正式巡查。
- 切换月份会清空抽屉与弹窗并把日期重置为首日；抽屉文本自带月份前缀（如 `十一月：…`），弹窗文本自带 `月份/日期` 前缀（如 `十一月/十七日：…`）。巡查以前缀与当前导航比对识别跨月缓存，不一致即记缺口。
- “模拟撤场”会把抽屉与弹窗置为取消/已撤场文本；该状态只存在于当前浏览器页面生命周期，新一轮巡查打开全新上下文。取消的持久化由收据状态机保证：`calendar_facts` 中 `cancelled` 事实拒绝后续在档观察覆盖。
- `calendar_visits` 是追加式访问收据（含 insert/revise/keep/reject 动作与原因），`calendar_facts` 按业务键保存当前版本与修订号；审阅层据缺口把月份判为 `draft` 或 `published`。
